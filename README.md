# 飞书网关助手

通过飞书机器人控制 OpenClaw 网关重启。

## 功能

- 📩 私聊机器人发送"重启网关"即可重启
- 🔒 首次发消息的用户自动成为授权管理员
- 📤 执行结果实时反馈到飞书

## 安装

```bash
npm install
```

## 运行

```bash
npm start
```

## 使用方法

1. 运行机器人服务
2. 在飞书中找到你的机器人，发送任意消息（首次会自动授权你为管理员）
3. 发送"重启网关"即可重启网关
4. 发送"帮助"查看可用命令

## 配置

编辑 `.env` 文件：

```env
APP_ID=你的飞书应用ID
APP_SECRET=你的飞书应用密钥
AUTHORIZED_USER_ID=授权用户的Open ID（首次运行后自动填写）
RESTART_SCRIPT=C:\Users\zhiyutong\Desktop\重启网关.bat
```

## 注意事项

- 需要保持服务运行才能接收消息
- 建议设置为开机自启动或后台服务
